# Public Sector Spending Analytics

A Python analysis of military, healthcare, and education spending across 10 countries from 2015–2020 using World Bank and SIPRI data.

The analysis explores spending trends, relationships with GDP, and growth across countries.

## Tech

Python · pandas · Matplotlib · Jupyter Notebook

## Files

- `Public Sector Spending Analytics.ipynb` — Full analysis, code, and visualizations
- `Presentation.pptx` — Presentation of findings
- `.xls` / `.xlsx` files — World Bank and SIPRI source data
- `.png` files — Visualizations generated from the analysis
